# Virtual Closet MVP v1

## Product goal

Build a private, single-user virtual wardrobe and outfit diary.

## Core functions

1. Upload a clothing photo
2. Enter category, color, and optional brand
3. Browse and search the closet
4. Create an outfit by manually selecting clothing items
5. Optionally attach an outfit photo
6. Show outfits in a calendar
7. Show wear count and last-worn date

## Clothing categories

- top
- bottom
- outerwear
- one_piece
- shoes
- accessory

## Explicitly out of scope

- social features
- shopping
- recommendations
- weather integration
- virtual try-on
- automatic matching from outfit photographs
- personalized AI avatar
- multiple users
- complicated onboarding
