# UI Reference — Personal Fashion Journal App

## 1. Product Identity

This app is not a wardrobe inventory manager.

It is a **private fashion journal** that helps the user:
- record daily outfits
- remember personal style moments
- understand their wardrobe
- reduce unnecessary purchases

The emotional feeling should be:

> "My personal fashion archive"

Not:

> "A database of clothes"

The app should feel like:
- a fashion magazine
- a personal lookbook
- a private diary
- a creative archive

---

# 2. Visual Direction

## Core Style

The visual language combines:

- 50% editorial fashion magazine
- 30% personal diary
- 20% modern fashion brand

Reference feelings:
- Vogue archive
- independent fashion portfolio
- luxury lookbook
- minimalist design studio

---

# 3. Design Principles

## 3.1 Image First

Photos are the most important content.

The UI should never compete with photos.

Prefer:
Large image

Small context

Minimal metadata


Avoid:


Many cards
Many buttons
Many labels


---

## 3.2 Editorial Layout

Layouts should feel curated.

Avoid traditional app grids.

Avoid:

- dashboard style
- excessive cards
- dense information

Prefer:

- asymmetric layouts
- magazine composition
- strong visual hierarchy


Example:

GOOD:
            LOOKS

          July 2026


          [large photo]

      27.07.2026
  
BAD:


Photo
Title
Category
Color
Brand
Button
Button


---

## 3.3 Typography as Design

Typography is a major visual element.

Use:

### Display typography

For:
- page titles
- months
- important moments

Style:
- elegant
- large
- confident


Examples:
Looks

July 2026

Today's Look

### Supporting typography

For:
- metadata
- categories
- dates

Style:
- clean
- minimal
- uppercase labels


Examples:


STYLE ARCHIVE

DAILY LOOK

TOP · IVORY


---

# 4. Color System

## Background

Warm paper / ivory.

Example:


#F7F4ED


The app should not feel pure white.

---

## Primary text

Soft black:


#1C1C1C


Avoid pure #000000.

---

## Secondary text

Warm gray:


#77736C


---

## Accent colors

Use sparingly.

Possible accents:

- muted olive
- warm orange
- lime yellow

Accent colors should appear as small moments, not the whole interface.

---

# 5. Components

## 5.1 Navigation

Navigation should be quiet.

Current:


LOOKS CALENDAR CLOSET


is acceptable.

But styling should be minimal.

Avoid:
- large pills
- heavy borders

Prefer:


Looks Calendar Closet


with subtle active indicator.

---

## 5.2 Buttons

Avoid large SaaS-style buttons.

Avoid:


BLACK ROUND BUTTON
SAVE


Prefer editorial actions:


Save →
Replace →
Edit →


Small, elegant, secondary.

---

## 5.3 Cards

Avoid database cards.

Avoid:


Grey rectangle
Item name
Category
Color


Prefer:


Image

Item name

Small metadata


The image represents the object.

---

# 6. Screen Guidelines

## Looks Tab

Purpose:

Daily outfit memory.

Main action:

Take today's photo.

Layout:


LOOKS

Date selector

Large outfit photo

Small date/context

Previous looks


The experience should feel like opening a diary.

---

## Calendar Tab

Purpose:

Browse outfit history.

Not a productivity calendar.

It should feel like:

"my style timeline"

Prefer:

- photo thumbnails inside dates
- visual memories
- month archive

Example:


July 2026

1 2 3

  [photo]

8 9 10

  [photo]

---

## Closet Tab

Purpose:

Understand wardrobe.

Not inventory management.

It should feel like:

"a personal collection"

Prefer:

- image gallery
- fashion archive
- collection view

Avoid:

- shopping catalog feeling
- too much metadata

---

# 7. Image Treatment

Images should have:

- large display area
- rounded corners
- natural cropping
- minimal overlays

Avoid:

- dark gradients
- too much text over images

Text should usually sit outside the image.

---

# 8. Motion

Animations should feel like:

- flipping a magazine
- opening a photo album

Prefer:

- smooth transitions
- subtle fades
- gentle movement

Avoid:

- flashy animations
- gamified interactions

---

# 9. Things To Avoid

Do NOT make the app look like:

- Notion
- inventory software
- shopping apps
- productivity dashboards
- social media feeds

Avoid:

- excessive buttons
- excessive information
- crowded screens
- strong app-like cards

---

# 10. Overall Success Criteria

When opening the app, the user should think:

"This feels like my own fashion magazine."

Not:

"This helps me organize my clothes."

The app should prioritize:
1. Memory
2. Beauty
3. Personal expression
4. Organization

in that order.
