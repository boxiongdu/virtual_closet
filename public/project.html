02 / Product decisions

Built for low-friction journaling.

The MVP prioritizes capturing an outfit in seconds. An image-first UI keeps the focus on personal style instead of inventory management. Clothing entries grow gradually alongside the daily diary.

03 / Engineering

One codebase, native and web.

Frontend
Expo React Native · TypeScript · Expo Router
State
Local-first React stores and AsyncStorage
Images
Native file storage and browser-specific image handling
Build
GitHub Actions · Expo web export
Privacy
No user account or cloud photo upload in this demo

Demo note: local data belongs to the visitor's browser/device. The current browser version is an MVP; clothing entries may not survive a page refresh, and large photo archives are not supported yet.
